Datos simulados del prototipo. La semilla vive en `semilla.js` (`SEMILLA`, `estadoInicial()`, `campanaFija()`, `CODIGOS`).

- `medios.js`: forma única del medio (comentario al inicio) y generador determinista.
- `catalogos.js`: plazas, calles, inmuebles, formatos y precios de muestra.
- `aleatorio.js`: azar con semilla fija (sin Math.random).
- `fechas.js`: fechas locales y plan de reportes.
